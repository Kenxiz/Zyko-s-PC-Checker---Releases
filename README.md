# Zyko's PC Checker Releases
This repository is the official public distribution and update repository for **Zyko's PC Checker**.

It contains published application releases, including the latest Windows executable, SHA-256 verification files, and release notes. The application uses this repository's GitHub Releases to check for and download new versions.

## Downloads
The latest version of Zyko's PC Checker can be found on the **Releases** page of this repository. Download the official `.exe` file and, when needed, use the included `.sha256` file to verify the downloaded release.

## Automatic Updates
Zyko's PC Checker can check this repository for newer published releases. When an update is available, the application can download the official release and verify its SHA-256 hash before installation.

Only published GitHub Releases are used for updates. Normal commits, branches, and repository activity do not trigger application updates.

## Source Code
The source code and development files for Zyko's PC Checker are maintained separately and are not included in this distribution repository. This repository is intended only for official compiled releases and update-related files.

## Security
Always download Zyko's PC Checker from an official published release. Release files may include SHA-256 verification information to help confirm that the downloaded file matches the published release.

SHA-256 verification helps detect accidental or unauthorized changes to a downloaded file, but it does not by itself prove the identity of the publisher. Future releases may also use additional publisher verification, including code signing.
